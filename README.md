# Live Range-Hunting Trading System

## اجزا
- `binance_feed.py` — دیتای زنده‌ی کندل از بایننس (API عمومی، بدون نیاز به کلید).
- `engine.py` — همون موتور تحلیل (رنگ میله، فشار حجمی، تشخیص رنج، منطق اسمارت-فلیپ) که در طول این پروژه ساختیم و بک‌تست شد.
- `iran_exchange_adapter.py` — **اسکلت خام**. چون صرافی API نداره، سفارش‌ها با شبیه‌سازی کلیک مرورگر (Playwright) زده میشن. تمام selectorها (`TODO`) باید با DevTools مرورگر خودت پیدا و جایگزین بشن.
- `live_bot.py` — حلقه‌ی اصلی که همه رو به هم وصل می‌کنه.

## قبل از اجرا
```bash
pip install requests pandas playwright
playwright install chromium
export IRAN_EXCHANGE_URL="https://..."
export IRAN_EXCHANGE_USER="..."
export IRAN_EXCHANGE_PASS="..."
```

## اجرای امن (فقط سیگنال، بدون معامله واقعی)
```bash
DRY_RUN=1 python3 live_bot.py
```

## اجرای زنده (فقط وقتی کاملاً مطمئن بودی)
```bash
DRY_RUN=0 python3 live_bot.py
```

## هشدارهای جدی
1. **من این کد رو زنده تست نکردم** — نه بایننس نه صرافی ایرانی تو محیط من در دسترس نیستن. حتماً قبل از پول واقعی، چند روز با DRY_RUN=1 اجراش کن و خروجی سیگنال‌ها رو با چارت واقعی مقایسه کن.
2. **آداپتور صرافی کامل نیست** — باید خودت selectorهای دکمه‌های خرید/فروش، لاگین، و بالانس رو با بازرسی صفحه (Inspect Element) پیدا کنی و جای TODOها بذاری.
3. **کپچا و احراز دومرحله‌ای** ممکنه کل اتوماسیون لاگین رو غیرممکن کنه — در این صورت، به‌جای اتوماسیون کامل، یک نشست مرورگر پایدار (persistent context) با لاگین دستی یک‌بار، و فقط اتوماسیون کلیک سفارش، گزینه‌ی واقع‌بینانه‌تریه.
4. **مسئولیت پولی** — این ربات با پول واقعی معامله می‌کنه. من مشاور مالی نیستم و این توصیه‌ی مالی نیست؛ ریسک از دست دادن سرمایه واقعیه، خصوصاً چون استراتژی هنوز در حال تکامل بوده (نسخه‌های اولیه‌ی همین پروژه ضررده بودن).
5. اندازه‌ی پوزیشن (`POSITION_SIZE`) پیش‌فرض صفره — عمداً، تا مجبور بشی آگاهانه یک عدد واقعی بذاری.
